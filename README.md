# AI Resume Analyzer & Job Portal

An AI-powered Resume Analyzer and Job Portal built with FastAPI. 
The system helps candidates analyze their resumes against job requirements, 
get an AI-based match score, identify missing skills, and receive personalized feedback.

##  Features

- User Signup & Login
- Candidate and Recruiter Roles
- Recruiter Job Posting
- Candidate Job Search
- Resume PDF Upload
- AI-powered Resume Analysis
- Resume-to-Job Match Score
- Match Percentage
- Missing Skills Detection
- Personalized Resume Feedback
- Candidate Applications
- Recruiter Applicant Dashboard
- Secure Authentication
- SQLite Database

##  Technologies Used

- Python
- FastAPI
- Jinja2
- SQLite
- Pydantic
- PyPDF
- JWT Authentication
- Passlib / Bcrypt
- Google Gemini AI
- HTML
- CSS
- JavaScript

##  AI Resume Analysis

The application analyzes a candidate's resume against a job's requirements and provides:

- Match Score
- Match Percentage
- Missing Skills
- Personalized Feedback
- Recommended Improvements

##  Candidate Features

Candidates can:

- Create an account
- Browse available jobs
- View job requirements
- Upload their resume in PDF format
- Apply for jobs
- Get AI-powered resume analysis
- View their resume match score and feedback

##  Recruiter Features

Recruiters can:

- Create an account
- Post job opportunities
- Add salary, location, experience and requirements
- View posted jobs
- View applicants
- Review candidate match scores
